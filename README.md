# MathSite

This repository is a Vite + React + TypeScript scaffold for a mathematics learning
platform designed for Netlify hosting with Netlify Identity.

Environment & deployment
- Configure Netlify Identity in your Netlify site settings (enable Identity)
- Set `API_BASE` or other env vars in Netlify dashboard as needed

Run locally

```bash
npm install
npm run dev
```

Build

```bash
npm run build
```
